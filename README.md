# Carte — บัตรส่วนตัว QR และคลังนามบัตร

เวอร์ชัน 2.0.0 · 13 พ.ย. 2026 (มีระบบองค์กร/บัตรพนักงาน) (เช็กได้ที่ล่างสุดของหน้าตั้งค่า)

แอปเว็บ (PWA) ติดตั้งบนหน้าจอโฮมได้ ใช้ Firebase โปรเจกต์ `mplb-2d630` ร่วมกับ MPLB

## ไฟล์ในโฟลเดอร์

| ไฟล์ | หน้าที่ |
|---|---|
| index.html | ตัวแอป |
| manifest.json | ชื่อแอป สี และไอคอน สำหรับติดตั้งบนหน้าจอโฮม |
| sw.js | ให้แอปเปิดเร็วและเปิดได้ตอนเน็ตไม่ดี |
| icon-192.png, icon-512.png | ไอคอนสำหรับ Android และ Chrome |
| apple-touch-icon.png | ไอคอนสำหรับ iPhone และ iPad |

---

## 1. ตั้งค่า Firebase (ทำครั้งเดียว)

### 1.1 Firestore Rules
1. เข้า https://console.firebase.google.com แล้วเลือกโปรเจกต์ **mplb-2d630**
2. ไปที่เมนูซ้าย **Build → Firestore Database** แล้วกดแท็บ **Rules**
3. ลบข้อความเดิมทั้งหมด แล้ววางเนื้อหาจากไฟล์ `firestore.rules` (ฉบับ 2.0 มีกฎขององค์กรด้วย) ซึ่งรวมกฎของ MPLB ไว้แล้ว
4. กด **Publish**

### 1.2 Authorized domains
1. ไปที่ **Build → Authentication** แล้วกดแท็บ **Settings**
2. เลือก **Authorized domains**
3. ต้องมี `mergeeatelier.github.io` ถ้ายังไม่มี ให้กด **Add domain** แล้วเพิ่ม

> ห้ามลบผู้ใช้ในหน้า Authentication → Users เพราะเป็นบัญชีของ MPLB ด้วย สิทธิ์เข้า Carte จัดการในแอปเอง

## 2. อัปขึ้น GitHub Pages

### ครั้งแรก
1. เข้า https://github.com/new
2. ตั้งชื่อ repository ว่า **Carte** เลือก **Public** แล้วกด **Create repository**
3. ในหน้า repo ที่สร้างเสร็จ กดลิงก์ **uploading an existing file**
4. ลากไฟล์ทั้งหมดในโฟลเดอร์นี้ไปวาง (ไม่ต้องลากโฟลเดอร์)
5. กด **Commit changes**
6. ไปที่ **Settings → Pages**
7. ตรง Source เลือก **Deploy from a branch** แล้วเลือก Branch เป็น **main** และโฟลเดอร์ **/ (root)** จากนั้นกด **Save**
8. รอ 1–2 นาที แอปจะอยู่ที่ **https://mergeeatelier.github.io/Carte/**

### อัปเดตเวอร์ชันใหม่
1. ในหน้า repo ไปที่ **Add file → Upload files** แล้วลาก `index.html` ตัวใหม่ไปวางทับ
2. เปิด `sw.js` บน GitHub กดดินสอเพื่อแก้ เปลี่ยน `carte-v1` เป็น `carte-v2` (เลขเพิ่มขึ้นทุกครั้งที่อัปเดต) แล้ว Commit
3. บนมือถือ ปิดแอปแล้วเปิดใหม่ 1–2 ครั้ง จะได้เวอร์ชันใหม่

## 3. ติดตั้งบนมือถือ

**iPhone (Safari)**
1. เปิด https://mergeeatelier.github.io/Carte/ ใน Safari
2. กดปุ่มแชร์ แล้วเลือก **เพิ่มไปยังหน้าจอโฮม** จากนั้นกด **เพิ่ม**

**Android (Chrome)**
1. เปิดลิงก์ใน Chrome
2. กดเมนู ⋮ แล้วเลือก **ติดตั้งแอป** หรือ **เพิ่มลงในหน้าจอหลัก**

---

## 4. ใช้งานครั้งแรก
1. ล็อกอินด้วย **mergee.atelier@gmail.com** ระบบจะตั้งเป็นแอดมินให้อัตโนมัติ
2. ตั้ง PIN 6 หลัก (จำไว้เฉพาะเครื่องนั้น)
3. ไปที่ **ตั้งค่า → ผู้ดูแลระบบ → จัดการผู้ใช้** แล้วเพิ่มอีเมลคนที่ให้ใช้ Carte
4. คนที่ถูกเพิ่ม เปิดลิงก์แล้วล็อกอินด้วย Google ด้วยอีเมลนั้นได้เลย

## แก้ปัญหา
- **"โดเมนนี้ยังไม่ได้อนุญาตใน Firebase"** ให้ทำข้อ 1.2
- **"ไม่มีสิทธิ์เข้าถึง · ตรวจ Firestore Rules"** ให้ทำข้อ 1.1 ใหม่ แล้วตรวจว่ากด Publish แล้ว
- **"…ไม่มีสิทธิ์ใช้งาน"** แปลว่าอีเมลนั้นยังไม่อยู่ในรายชื่อ ให้แอดมินเพิ่มในแอป
- **กดปุ่ม Google จากไอคอนหน้าจอโฮมบน iPhone แล้วไม่มีอะไรขึ้น** ใช้ผ่าน Safari ไปก่อน (แอปบนหน้าจอโฮมไม่ได้ใช้การล็อกอินร่วมกับ Safari) ถ้าต้องการให้ไอคอนใช้ได้แน่นอน ให้ย้ายไปฝากบน Firebase Hosting (ฟรี)
- **สแกน QR แล้วกล้องไม่เปิด** ไปที่ ตั้งค่า iPhone → Safari → กล้อง แล้วเลือก "ถาม" หรือ "อนุญาต"
- **อ่านรูปนามบัตรครั้งแรกช้า** ครั้งแรกต้องโหลดตัวอ่านภาษาไทยและอังกฤษ (ประมาณ 10–20 วินาที) ครั้งต่อไปจะเร็วขึ้น
